# LIFE 0.3 — комплект без вложенных папок

Настройки Firebase проекта life-planner-d1fd1 уже заполнены.

## Как обновить существующий сайт

1. Распакуйте архив.
2. Откройте https://github.com/gevorg0410/life-planner .
3. Нажмите Add file → Upload files.
4. Загрузите ВСЕ файлы из архива прямо в корень репозитория, подтвердив замену существующих. Папки icons и vendor в этой версии не нужны: все ссылки адаптированы для файлов в корне.
5. Нажмите Commit changes.
6. Дождитесь завершения публикации во вкладке Actions (зелёная отметка).
7. Откройте https://gevorg0410.github.io/life-planner/ и обновите страницу. Если предлагается обновление приложения, нажмите «Обновить приложение».

## Проверка

Войдите почтой и паролем из Firebase Authentication. Создайте тестовую задачу. Дождитесь «Сохранено в облаке» и проверьте задачу на другом устройстве с тем же аккаунтом.
Первое открытие аккаунта на устройстве требует интернета. После первой загрузки файлы приложения сохраняются для открытия без сети. Изменения без интернета сохраняются в локальной очереди и отправляются после подключения.

Настоящий вход в ваш аккаунт и синхронизация с вашей базой при подготовке архива не выполнялись. Проверены пути к файлам, синтаксис и офлайн-кэш.

## Firebase

В Authentication должен быть включён Email/Password и создан пользователь. В Firestore должна быть база (default). Содержимое firestore.rules нужно опубликовать в Firestore → Rules; загрузка файла на GitHub сама по себе правила не применяет.
Домен gevorg0410.github.io добавьте в Authentication → Settings → Authorized domains.

## Перенос старых данных

В старом LIFE_v0.2.html в привычном браузере нажмите «Экспортировать резервную копию». На новом сайте войдите в аккаунт и импортируйте этот JSON. Импорт заменяет данные текущего аккаунта, поэтому перед ним экспортируйте имеющиеся записи. JSON содержит ваши личные данные: в публичный репозиторий его загружать не нужно.

## Обновления и хранение

При следующих изменениях файлов меняйте VERSION в sw.js на новое уникальное значение, чтобы обновился офлайн-кэш.
Данные разделены по аккаунтам. При одновременном редактировании одной записи сохраняется последняя принятая облаком версия. Разные записи синхронизируются отдельно.
Локальная копия и очередь хранятся в браузере. Очистка данных браузера удаляет ещё не отправленные изменения. Экспортируйте резервные копии.

## Установка

Android/Chrome: меню → «Установить приложение». iPhone/Safari: «Поделиться» → «На экран Домой». На компьютере используйте кнопку установки в поддерживающем браузере.
